# LLM and automated-use policy

Machine-readable crawler rules: robots.txt at the site origin (repository root
when deployed to GitHub Pages).

This file states restrictions for operators of language models, crawlers, and
other automated systems that access this site.

## Disallowed without explicit written permission

1. Using pages, text, code, metadata, or derived representations from this site
   to train, fine-tune, align, evaluate, or otherwise improve machine learning
   or artificial intelligence models (including large language models).

2. Collecting, aggregating, or redistributing site content at scale for
   datasets, corpora, embedding stores, or similar resources used in model
   development or deployment.

3. Large-scale automated scraping, crawling, harvesting, or bulk downloading
   of this site or its assets when the primary purpose is model training,
   dataset building, or comparable bulk reuse.

## Allowed

Individual end users and ordinary browsing, accessibility tools, and limited
technical access needed to display or use the site as intended (e.g. normal
HTTP requests from a browser).

Search engines may index public pages for search results only, subject to
robots.txt when present; indexing does not grant permission to use indexed
content for AI model training.

## No waiver

Absence of a robots.txt entry or technical block does not imply consent for
training, scraping, or bulk collection for AI or dataset purposes.
