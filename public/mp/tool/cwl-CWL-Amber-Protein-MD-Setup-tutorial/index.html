cwl-amber-protein-md-setup-tutorial

Overview

This Common Workflow Language (CWL) workflow automates the preparation of a protein system for Molecular Dynamics (MD) simulations. Based on the logic of the classic GROMACS lysozyme tutorial, this implementation utilizes the BioExcel Building Blocks (biobb) library to wrap the AmberTools MD package, ensuring a reproducible and standardized setup process.

The pipeline executes a series of structural preparation and refinement steps:

  • Structure Cleaning: Extracts the target molecule and optimizes the PDB structure using Pdb4amber.
  • System Solvation: Generates the system topology, adds water molecules (solvation), and neutralizes the system with counterions.
  • Energy Minimization: Performs an initial energy minimization using Sander to remove steric clashes, followed by output processing and coordinate conversion.

This workflow is licensed under Apache-2.0 and is designed to provide a seamless transition from a raw PDB structure to a minimized, solvent-equilibrated system ready for production MD runs. Detailed documentation and version history can be found on WorkflowHub.
