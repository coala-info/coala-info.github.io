scimap

Overview

Scimap works on a cell-by-marker table (one row per segmented cell, one column per marker) held in an AnnData object. For cell typing it does two things: it sets a gate for each marker (sm.pp.rescale), and it assigns each cell a phenotype from a marker hierarchy you write (sm.tl.phenotype_cells). It also has spatial tools (sm.tl.spatial_distance, spatial_count, spatial_interaction, spatial_lda).

The tool does the bookkeeping. The cell types are only as good as the marker table and the gates. Most wrong labels come from using a state marker as a lineage marker, or from a gate that sits in the background. The last three sections cover both.

Image

  • labsyspharm/scimap:2.2.11 holds scimap 1.3.2 on Python 3.8. The tag names the image line, not the package version, and latest holds the same package. The functions below are the 1.3.2 ones.
  • Pass the image as docker_image on the script call that imports scimap. It needs no network.
  • import scimap as sm prints an OpenGL warning; ignore it.

Input

import pandas as pd, anndata as ad, scimap as sm
df = pd.read_csv("cells.csv")                       # one row per cell
markers = [...]                                     # the marker columns, in panel order
a = ad.AnnData(df[markers].to_numpy(float))
a.var_names = markers
a.obs = pd.DataFrame({"imageid": df["sample_id"].astype(str).values,     # one id per image / ROI
                      "cluster": df["cluster"].astype(str).values},
                     index=df.index.astype(str))

imageid is the column scimap uses to tell images apart. Keep any existing cluster column in obs.

Gate each marker

a = sm.pp.rescale(a, gate=None, log=False, method="all")   # GMM gate for every marker
gates = a.uns["gates"]                                      # the gate used for each marker
  • After rescale, a.X runs from 0 to 1 with 0.5 at the gate: a value above 0.5 means the cell is positive. The input is kept in a.raw.
  • With gate=None the gate is found per marker by a two-component Gaussian mixture and set halfway between the two component means. log=True (the default) takes log1p first, which suits raw ion counts. Use log=False when the values are already transformed or scaled to 0–1.
  • method="all" fits one gate over all images, and "by_image" fits one gate per image. Per-image gates follow batch effects, but they fail on an image with few positive cells.
  • Manual gates: pd.DataFrame({"marker": ["CD3", "CD68"], "gate": [0.3, 0.45]}), on the input scale (after log1p when log=True). Markers left out get a GMM gate.
  • Cells whose value equals the gate value become exactly 0.5. When the gate falls on a value many cells share (often 0), all of them sit at 0.5, so count positives with > 0.5, not >= 0.5.
  • Check every lineage gate. Print, for each marker, the share of all cells above its gate, and the share in each cluster. A lineage marker that is positive in a large part of every cluster has its gate in the background, from spill-over, non-specific staining or a skewed distribution. Raise that gate by hand, or read that marker only relative to other clusters.

Phenotype cells

wf = pd.read_csv("workflow.csv")
a = sm.tl.phenotype_cells(a, phenotype=wf, gate=0.5, label="phenotype")
a.obs["phenotype"].value_counts()
  • Rules: pos, neg, anypos (any one listed marker positive), anyneg, allpos, allneg.
  • Each phenotype gets a score from its rules on the rescaled values, and a cell takes the phenotype with the highest score at each level. A cell with no score above the gate at the top level is Unknown. A cell that cannot be split further keeps its parent's label, such as Immune or T_cell.
  • likely-<name>: the cell won on pos markers, but one of them is below the gate. Decide these yourself; do not drop them.
  • Per-cell gating is noisy for small cells next to large ones (see spill-over below). To label existing clusters, use the cluster table in the next section and treat the per-cell phenotypes as one input.

Label clusters

X = pd.DataFrame(a.X, columns=a.var_names, index=a.obs_names)
pos_share = (X > 0.5).groupby(a.obs["cluster"]).mean()      # share of cells above each gate
mean_scaled = X.groupby(a.obs["cluster"]).mean()
pheno_share = pd.crosstab(a.obs["cluster"], a.obs["phenotype"], normalize="index")

For each cluster, print the lineage markers with their share of positive cells, sorted, and the size of the cluster. Label it from the lineage markers that dominate, using the rules below. Print the top three lineage markers beside each label you write.

State markers are not lineage markers

These follow a cell's state or location, not its lineage. Never use them to decide a cluster's lineage (inside a lineage, some of them define a subtype; see the table above):

  • Hypoxia and angiogenesis: CAIX, HIF-1α, GLUT1, VEGF. Macrophages in hypoxic tumor regions carry them, and so do fibroblasts and tumor cells.
  • Proliferation: Ki-67, PCNA, phospho-histone H3. Proliferating T cells and macrophages carry them too.
  • Checkpoints and activation: PD-L1, PD-1, LAG3, TIM3, ICOS, OX40, CTLA-4, IDO, CD38, CD27, CD127, CD69.

A cluster high in CAIX or VEGF that also carries two myeloid markers is myeloid. A cluster high in Ki-67 that carries CD3 is T cells.

Rules for labelling clusters

  1. Lymphoid markers first. Lateral spill-over at cell contacts adds the neighbours' markers to a cell, and small lymphocytes beside large macrophages or fibroblasts pick up those markers. CD3 or CD20 in most cells of a cluster is strong evidence. Myeloid or stromal signal in that cluster is often spill-over.
  2. Myeloid on two markers. CD68 also stains some tumor cells, and in many panels it has a broad background. Call a cluster myeloid when two myeloid markers (CD68, CD163, CD14, CD16, CD11b, CD11c, CD64) are positive in a large share of its cells.
  3. Stroma on one dominant marker. A cluster whose strongest lineage signal is one stromal or matrix marker is stroma. Collagen I alone is matrix-rich stroma, αSMA alone is myofibroblasts, pericytes or vessel wall, and CD31 alone is endothelium.
  4. Tumor by exclusion when the panel has no tumor marker. Some panels carry no SOX10, MelanA, S100 or cytokeratin. Then tumor cells are the clusters with no immune, myeloid or stromal lineage marker above the gate in most cells. Vimentin, AXL and state markers do not change that.
  5. Two lineages in one cluster. Compare the two shares, and look at whether the two markers share cells or only touch. A small share of a second lineage is spill-over; label the dominant lineage.
  6. Marker-poor immune cells (for example HLA-DR-negative or CD45-low macrophages) still carry their lineage marker above the background of the other clusters. Compare each cluster with the rest, not only with the gate.

Checks after labelling

  1. List each class with its clusters, cell count and share of all cells. A class that holds half the cells, or none, needs a second look.
  2. For each cluster labelled tumor, print its top myeloid and stromal shares. Two myeloid markers in most cells, or one dominant stromal marker, means the label is wrong.
  3. For each cluster labelled myeloid or stroma, check that the evidence is lineage markers, not CAIX, VEGF, Ki-67 or PD-L1.
  4. Lymphoid clusters: CD8 against CD4, FOXP3 for regulatory T cells, and both CD4 and CD8 for double-positive cells. Use the share of positive cells, not the mean.
