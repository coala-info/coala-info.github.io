funannotate

Overview

This workflow provides a comprehensive pipeline for the structural and functional annotation of fungal and eukaryotic genomes using the Funannotate suite. It integrates multiple data sources, including a genome assembly, RNA-Seq reads (forward and reverse), protein evidence sequences, and optional alternate annotations, to produce high-quality gene models and functional descriptions.

The process begins by mapping RNA-Seq data with RNA STAR to provide transcriptomic evidence. Funannotate predict then utilizes this evidence alongside protein sequences to generate initial gene predictions. These predictions are further enriched through functional analysis using eggNOG Mapper and InterProScan, which assign biological roles and protein domains to the predicted genes.

In the final stages, Funannotate functional consolidates the structural and functional data into standard formats such as GFF3, GenBank, and FASTA (CDS, mRNA, and proteins). The workflow also includes comparative and quality control steps, utilizing Funannotate compare for multi-genome analysis, AEGeAn ParsEval for annotation comparison, and BUSCO to assess the completeness of the annotated gene set.

The final outputs are visualized through a JBrowse instance, allowing for interactive exploration of the genome features. This pipeline is licensed under GPL-3.0-or-later and is tagged for genome-annotation tasks.

Inputs and data preparation

StepLabelTypeNotes
0Genome assemblydata_inputThe genome sequence that you wish to annotate, in fasta format. It needs to be soft masked beforehand.
1RNASeq reads forwarddata_inputSome RNASeq data, forward reads, in fastq format
2RNASeq reads reversedata_inputSome RNASeq data, reverse reads, in fastq format
3Protein evidence sequencesdata_inputSome protein sequences to align on the genome to help annotation
4NCBI submission templatedata_inputA submission template retrieved from NCBI (generate it on https://submit.ncbi.nlm.nih.gov/genbank/template/submission/)
5Alternate annotation gbkdata_inputThe genbank output of an alternate annotation (for comparison)
6Alternate annotation gff3data_inputThe gff3 output of an alternate annotation (for comparison)

Ensure your genome assembly is in FASTA format and provide RNA-seq reads as paired-end fastqsanger datasets or collections for accurate splice-site mapping via STAR. Protein evidence should be supplied as a FASTA file, while optional NCBI templates and alternate annotations (GBK/GFF3) must strictly follow standard formatting to avoid parsing errors during the prediction and functional annotation stages. For large-scale runs, you can automate parameter setup using planemo workflow_job_init to generate a job.yml file. Refer to the README.md for comprehensive details on specific tool parameters and database requirements.

How to run (Planemo)

Local Galaxy (default engine)

planemo run Genome annotation with Funannotate.ga job.yml --download_outputs --output_directory . --output_json output.json

Optional: --galaxy_root /path/to/galaxy speeds up spinning up a local Galaxy.

Docker Galaxy

Append e.g. --engine docker_galaxy --ignore_dependency_problems (requires Docker).

External Galaxy (usegalaxy.org / EU / …)

planemo run Genome annotation with Funannotate.ga job.yml --engine external_galaxy --galaxy_url SERVER_URL --galaxy_user_key YOUR_API_KEY

Create a reusable profile: planemo profile_create myprofile --galaxy_url ... --galaxy_user_key ... --engine external_galaxy then planemo run Genome annotation with Funannotate.ga job.yml --profile myprofile.

Job file

  • Generate a template: planemo workflow_job_init Genome annotation with Funannotate.ga -o job.yml
  • Lint: planemo workflow_lint Genome annotation with Funannotate.ga

See Running Galaxy workflows in the Planemo documentation.

Invocation outputs

After a successful run with --download_outputs, files appear under your chosen --output_directory. --output_json records CWL-style metadata for outputs (paths, checksums).

On an external Galaxy, use planemo invocation_download INVOCATION_ID --profile ... to fetch outputs, or track progress with planemo workflow_track INVOCATION_ID.

Workflow steps marked as workflow outputs in the editor are listed under Workflow outputs; exact filenames depend on tools and Galaxy configuration.
