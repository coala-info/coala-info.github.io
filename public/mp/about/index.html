About

This site is a catalogue for discovering and downloading SKILL.md files and MCP definitions (including CWL) for CLI tools and workflows used with the Coala ecosystem. It exists to support exploration and research workflows—not as a guarantee of fitness for any particular purpose.

Install and use Coala

1. Install the client

Install the Coala client with pip.

pip install coala-client

2. Search for a tool

Search the catalogue by name or keyword. Use --category to filter by a category from the browse page.

coala search bwa
coala search anndata --category "Python library"

3. Add a tool as an MCP server

Import the tool’s CWL definitions as an MCP server in .agents/mcps/ of the current directory. Then list the configured servers.

coala mcp bwa
coala mcp-list

4. Add a skill

Download the tool’s SKILL.md into .agents/skills/ of the current directory so your agent can use it.

coala skill bwa

Add --global to coala mcp or coala skill to install into ~/.agents/ for all projects. Run coala --help to see all commands.
